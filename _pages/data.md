## Free data sources

A working list of open data portals I use regularly, grouped by type. All are free; some require a no-cost account.

Last reviewed July 2026. If a link has broken, [let me know](mailto:naiem.sheikh@okstate.edu).

### Satellite imagery

| Source | What you get |
| --- | --- |
| [USGS EarthExplorer](https://earthexplorer.usgs.gov/) | Full Landsat archive (1972–present), ASTER, aerial photography |
| [Copernicus Data Space](https://dataspace.copernicus.eu/) | Sentinel-1, -2, -3, -5P |
| [NASA Earthdata Search](https://search.earthdata.nasa.gov/) | MODIS, VIIRS, SMAP, GPM, ECOSTRESS |
| [LP DAAC](https://lpdaac.usgs.gov/) | MODIS and VIIRS land products |
| [HLS](https://hls.gsfc.nasa.gov/) | Harmonized Landsat + Sentinel-2, 30 m |

### Cloud platforms

| Source | What you get |
| --- | --- |
| [Google Earth Engine](https://earthengine.google.com/) | Petabyte catalog, JavaScript and Python APIs |
| [Microsoft Planetary Computer](https://planetarycomputer.microsoft.com/) | STAC catalog with hosted JupyterHub |
| [AWS Open Data](https://registry.opendata.aws/) | Landsat, Sentinel-2, NAIP in public S3 buckets |
| [GEE Community Catalog](https://gee-community-catalog.org/) | Community datasets not in the official GEE catalog |

### Agriculture

| Source | What you get |
| --- | --- |
| [CroplandCROS](https://croplandcros.scinet.usda.gov/) | USDA Cropland Data Layer, 10 m from 2024 |
| [CDL bulk download](https://www.nass.usda.gov/Research_and_Science/Cropland/Release/index.php) | National CDL rasters by year |
| [USDA NASS Quick Stats](https://quickstats.nass.usda.gov/) | County and state yield, acreage, production |
| [AmeriFlux](https://ameriflux.lbl.gov/) | Eddy covariance flux tower measurements |
| [USDA Ag Data Commons](https://agdatacommons.nal.usda.gov/) | Data from USDA-funded research |
| [FAOSTAT](https://www.fao.org/faostat/) | Global agricultural statistics by country |

### Weather and climate

| Source | What you get |
| --- | --- |
| [Oklahoma Mesonet](https://www.mesonet.org/) | 120+ Oklahoma stations, 5-minute intervals |
| [PRISM](https://prism.oregonstate.edu/) | 4 km gridded US climate |
| [Daymet](https://daymet.ornl.gov/) | 1 km daily weather, North America, 1980– |
| [gridMET](https://www.climatologylab.org/gridmet.html) | 4 km daily US meteorology, reference ET, drought indices |
| [ERA5](https://cds.climate.copernicus.eu/) | Global hourly reanalysis, 1940– |
| [NOAA Climate Data Online](https://www.ncei.noaa.gov/cdo-web/) | Station observations and normals |

### Administrative boundaries

| Source | What you get |
| --- | --- |
| [geoBoundaries](https://www.geoboundaries.org/) | Global admin boundaries, open license |
| [GADM](https://gadm.org/) | Global admin areas (non-commercial use) |
| [Natural Earth](https://www.naturalearthdata.com/) | Public domain basemap vectors |
| [US Census TIGER/Line](https://www.census.gov/geographies/mapping-files/time-series/geo/tiger-line-file.html) | US states, counties, tracts, roads, water |
| [Geofabrik](https://download.geofabrik.de/) | OpenStreetMap extracts by country |

### Terrain and soils

| Source | What you get |
| --- | --- |
| [USGS 3DEP](https://www.usgs.gov/3d-elevation-program) | US elevation, 1 m lidar where available |
| [Copernicus DEM](https://spacedata.copernicus.eu/collections/copernicus-digital-elevation-model) | Global 30 m DEM |
| [SRTM](https://www.earthdata.nasa.gov/data/instruments/srtm) | Near-global 30 m elevation |
| [Web Soil Survey](https://websoilsurvey.nrcs.usda.gov/) | US SSURGO soil properties |
| [SoilGrids](https://soilgrids.org/) | Global gridded soil properties, 250 m |
